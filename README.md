Цей репозиторій містить виконання лабораторних робіт (1-4) зі створення клієнт-серверного веб-застосунку. 

Проект являє собою лендінг майстерні з відновлення старої електроніки із формою зворотного зв'язку, яка працює через REST API.



## 🛠 Технології

* **Frontend:** HTML5, CSS3 (з підтримкою темної теми), Vanilla JavaScript

* **Backend:** Python 3, Flask (REST API)

* **Інфраструктура:** Docker, Docker Compose



## 🚀 Як запустити проект (Лабораторна 4)



Для запуску проекту на вашому комп'ютері повинен бути встановлений **Docker** та **Docker Desktop**.



1. Склонуйте репозиторій або завантажте файли проекту.

2. Відкрийте термінал (або командний рядок) у кореневій папці проекту.

3. Виконайте команду для збірки та запуску контейнера:

    ```bash
    docker compose up --build
    ```

Дочекайтеся повідомлення Running on http://127.0.0.1:5000 у терміналі.



## 🧪 Як протестувати роботу

Відкрийте браузер та перейдіть за адресою: http://localhost:5000



Ви побачите головну сторінку проекту з анімаціями появи тексту.



Спробуйте перемикач темної/світлої теми у правому верхньому куті.



Прокрутіть до секції "Заявка на відновлення".



Заповніть форму. Якщо у випадаючому списку обрати "Інше", плавно з'явиться додаткове поле для вводу.



Натисніть "Відправити заявку".



Дані будуть відправлені на Python-сервер без перезавантаження сторінки (через fetch), і ви побачите повідомлення про успішну відповідь від сервера.



## 🛑 Як зупинити сервер

Щоб зупинити роботу контейнера, натисніть Ctrl + C у терміналі, де він запущений, або виконайте команду:

    
    docker compose down
